# Move Studio · App independiente

App autocontenida de entrenamiento en casa. No requiere NIGHTVIS LAB, frameworks, cuenta ni conexión para usar sus rutinas.

## Usar

Abre index.html o publica el contenido de este ZIP como sitio estático en GitHub Pages. El service worker habilita caché offline después de una primera visita HTTPS.

## Perfiles

- **N1GHT (16):** tres planes de fuerza en casa, sin equipo de gimnasio, con indicaciones de técnica, descanso y supervisión adulta. Cualquier meta de peso o nutrición debe revisarse con su tutor y un profesional pediátrico.
- **NANI Cirueli (53):** caminata/marcha suave y dos rutinas de fuerza de bajo impacto para casa, ajustables a su comodidad y condición.

Las sesiones se guardan por separado en el navegador. Usa los botones de respaldo para exportar o importar los datos de la app. Las rutinas son orientación general, no diagnóstico ni tratamiento.
